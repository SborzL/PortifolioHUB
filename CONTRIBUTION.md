# Contribution Guide – PortifolioHUB

Obrigado por querer contribuir com o **PortifolioHUB**! 🎉  
Este documento explica como colaborar, sugerir melhorias e enviar mudanças de forma organizada.

---

## 🚀 Como Contribuir

Existem várias formas de ajudar o projeto:

- Reportar problemas e bugs  
- Sugerir novas funcionalidades  
- Melhorar a documentação  
- Melhorar a organização do código  
- Otimizar HTML, CSS e JavaScript  
- Adicionar correções visuais ou estruturais  

Todas as contribuições são bem-vindas!

---

## 🛠️ Preparando o Ambiente

1. Faça um **fork** deste repositório.  
2. Clone o fork localmente:

   ```bash
   git clone https://github.com/seu-usuario/PortifolioHUB.git

## 🛠️ Fluxo de Trabalho para Contribuir

1. Acesse a pasta do projeto **PortifolioHUB** no seu computador.

2. Crie uma nova branch para trabalhar nas suas alterações.  
   - Use um nome que explique o que você vai modificar.  
   - Exemplo de nomes de branch:  
     - `ajuste-layout`  
     - `corrige-botao`  
     - `nova-secao-portfolio`

3. Realize todas as modificações necessárias no código.  
   - Ajuste arquivos, melhore estilos, corrija bugs ou adicione funcionalidades.  
   - Mantenha um padrão de organização e clareza.

4. Teste suas alterações.  
   - Verifique se tudo funciona como esperado.  
   - Certifique-se de que nada quebrou no restante do projeto.

5. Registre suas mudanças com uma mensagem de commit clara e objetiva.  
   - A mensagem deve explicar resumidamente o que foi alterado.  
   - Exemplo: *"Corrige alinhamento da seção de projetos"*  
   - Evite mensagens vagas como *"update"* ou *"mudanças"*.

6. Envie sua branch para o repositório remoto.  
   - Isso permitirá abrir um Pull Request e compartilhar suas alterações.

7. Abra um **Pull Request** para a branch `main`.  
   - Descreva o que você fez.  
   - Caso sua alteração seja visual, inclua imagens comparando antes e depois.  
   - Aguarde revisão e possíveis solicitações de ajuste.

## 📌 Boas Práticas para Pull Requests

- Descreva suas alterações de forma clara.  
- Se estiver corrigindo um bug, mencione o número da Issue (ex.: *Resolve #3*).  
- Prefira PRs pequenos e diretos.  
- Mantenha a consistência do código.  
- Inclua imagens de antes/depois ao alterar algo visual.

---

## 💬 Issues e Discussões

- Antes de sugerir grandes mudanças, abra uma **Issue**.  
- Explique seu raciocínio de forma objetiva.  
- Respeite os demais colaboradores.

---

## 🤝 Código de Conduta

Ao contribuir, você concorda em:

- Tratar todos com respeito.  
- Evitar linguagem ofensiva.  
- Manter um ambiente amigável e profissional.
