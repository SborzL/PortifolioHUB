# 🛡️ Política de Segurança do PortfolioHUB

## 1. Versões Suportadas

O desenvolvimento deste portfólio é mantido na versão principal (`main`). Apenas a versão mais recente do site hospedado no GitHub Pages é suportada e considerada em produção.

## 2. Relatório de Vulnerabilidades

A segurança deste projeto é levada a sério. Se você encontrar uma vulnerabilidade neste portfólio ou em algum dos projetos contidos nele, siga os seguintes passos:

* **Não divulgue publicamente** a vulnerabilidade.
* Entre em contato imediatamente via e-mail para: `[Seu E-mail Profissional Aqui]`
* Forneça o máximo de detalhes possível sobre a falha e os passos para reproduzi-la.

## 3. Práticas de Codificação Segura (Gemini's Guidance)

[cite_start]As seguintes práticas são seguidas para garantir a segurança e a conformidade do código:

* **Não Comitar Credenciais:** Senhas, chaves de API ou quaisquer dados sensíveis não devem ser adicionados ao repositório público. O arquivo `.gitignore` é rigorosamente aplicado para prevenir isso.
* **Validação de Dados:** Em qualquer script ou código (se houver), a entrada de dados do usuário é sempre validada.
* **Uso de HTTPS:** O portfólio é hospedado via GitHub Pages, que força o uso de HTTPS, garantindo a criptografia da comunicação entre o usuário e o servidor.

## 4. Gestão de Contribuições (Controle de Acesso)

Todas as alterações no código principal (branch `main`) são rigorosamente controladas através de Pull Requests, conforme detalhado nas Regras de Proteção de Branch.
